# PlaseSent

AI-driven cold email automation and deliverability platform — marketing website.

- `index.html` — the full marketing site (single self-contained static export)
- Brand: PlaseSent (plasesent.com / plasesent.ai — domains checked available on Namecheap, not yet bought)
- Built as a static site; the Get Started form is a front-end flow only, no backend / no real accounts.

## View locally

Open `index.html` in a browser, or serve it:

```sh
python3 -m http.server 8000
```

## Deploy

Any static host works (GitHub Pages, Vercel, Netlify, Cloudflare Pages). For GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
